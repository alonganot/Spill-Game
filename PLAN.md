# PLAN.md — Spill Development Roadmap

## Current Focus
**Milestone 8 done and released (v2.0.0). Milestone 8.5 (small fixes and additions) done. Milestone 9 (Spell Upgrades, `+`) done on the `milestone-9` branch; Milestone 10 (Meta-Progression & Playable Characters) done on the `milestone-10` branch; Milestone 10.5 (Gold Interest, Issue #11) done and merged; Milestone 10.6 (Gold Paint, Issue #12) done on the `feat/gold-paint` branch; Milestone 11 (Cosmic Paint Workshop UI overhaul, `DESIGN.md`) follows.** V1 is a PC game: it fills a desktop screen, stays playable on a phone-sized window, and ships as a Windows app (Electron, `npm run dist:win` builds `release/Spill-Setup-<version>.exe`); mobile app builds are out of V1. A full 15-fight run (3 acts, multi-enemy fights from fight 4) with a main menu, seeded runs, rewards, a dice shop, pixel-art sprites, and beat-by-beat combat playback is playable via `npm run dev` (`src/ui/RunScreen.tsx`, driven by `useRun` and `src/engine/run.ts`).

### Milestone 9: Spell Upgrades (`+`)
Each upgradable spell can be upgraded once per run to a `+` form with stronger numbers and the same color cost (RULES.md §2 and §4). Upgrades come from Reward stops (Free Spell Upgrade) and Shop stops (Spotlight, Draft, Targeted). Upgraded spells get a Chroma Aura (DESIGN.md §6.6). Saves: `RunState` gains `upgradedSpells`, and new shop and reward draws use the run RNG, which changes seeded results. So `SAVE_KEY` moves to `spill.run.v4` (old saves are dropped), and this ships as a **major** release, as with Milestone 8.

**Proposed upgrade table** (current stats → `+`; spells not listed have no upgrade):

|---|---|---|---|
| Ember | Red | 4 dmg | 6 dmg |
| Ripple | Blue | 4 block | 6 block |
| Thorn | Green | 2 poison | 4 poison |
| Inferno | Red ×2 | 6 dmg, 1 burn | 8 dmg, 2 burn |
| Tidal Wall | Blue ×2 | 10 block | 14 block |

| Steam Burst | Purple | 7 dmg, 3 block | 10 dmg, 3 block |
| Toxic Tide | Cyan | 3 poison, 4 block | 4 poison, 6 block |
| Wildfire | Orange | 1 burn, 3 poison | 2 burn, 4 poison |
| Splash | Purple + Red | 4 dmg (all) | 8 dmg (all) |
| Miasma | Cyan + Green | 2 poison (all), 5 block | 4 poison (all), 5 block |
| Purify | White | 3 block, cleanse | 5 block, cleanse |
| Aegis | White ×2 | 12 block (16 if cleansed) | 16 block (20 if cleansed) |

| Plague Burst | Blight | 2 poison, ×2 poison | 3 poison, ×3 poison |

Decisions: the Reward's third offer is a Free Spell Upgrade or a Free repaint at even odds; Spotlight, Draft, and Targeted are each once per shop visit; a Draft is paid first and its pick is mandatory (no Cancel, survives a reload, blocks Leave shop); the Targeted price rises with shop-bought upgrades only.

Every spell now has an upgrade. Spore Cloud (Green ×2, an area Poison spell) is new in this milestone, so there are 24 spells. Prism+ adds Chill to its damage, Hex+ curses every enemy (area), and Hush+ leaves the target without Silence Immunity, so it can be silenced again right after its action.

Burn needs no schema change: each Burn effect already adds one stack, so Inferno+ and Wildfire+ list a second Burn effect. Area spells roughly double on upgrade, because they cost two colors and hit every enemy; the numbers are a first proposal, to be checked by the balance run in Task 4.

### Milestone 10: Meta-Progression & Playable Characters
Between runs, the player earns Essence and spends it to unlock starting characters, each with its own starting dice and max HP (RULES.md §4). The active run stays a seed plus actions; Essence and unlocks live in their own save, `spill.meta.v1`. The run save moves to `spill.run.v5` (see below), so this ships as a **major** release.

**Numbers:** unlock costs **500 Essence (Tier 1)** and **2,000 (Tier 2)**; Essence per run = remaining gold ÷ 5 (rounded down) + 3 per fight won + 30 on victory; Tank 42 HP, Healer 28 HP (set by the Task 4 balance pass and the Miasma buff); unlocks in any order; every character starts with a dice cap of 3.

**Payout rules:** only a run that is **won or lost** pays. Abandon and Restart pay nothing. Runs started from a typed Settings seed (`seeded: true`) pay nothing; Replay seed / Restart of a random run stay unmarked and still pay.

| Id | Name | Tier | Cost | Starting dice | Max HP |
|---|---|---|---|---|---|
| `apprentice` | Apprentice | Starter | free | Standard ×2 | 40 |
| `warrior` | Warrior | 1 | 500 | Ember ×2 | 40 |
| `tank` | Tank | 1 | 500 | Lagoon + Standard | 42 |
| `venom` | Venom | 1 | 500 | Moss + Tide | 40 |
| `demon` | Demon | 2 | 2,000 | Standard + Shade | 40 |
| `healer` | Healer | 2 | 2,000 | Standard + Halo | 28 |

Ember, Lagoon, Moss, and Tide already exist (`src/data/dice.ts`). **Shade** (Black ×4, Red, Green) and **Halo** (White ×4, Red, Blue) are new dice, starting dice only: they are not added to the shop.

**Save compatibility:** `RunSave` gains an optional `characterId` (a save without it is the Apprentice). The Miasma Block buff and the Hush rule (below) change how saved actions replay: a v4 save could come back with different HP, or fail partway and be dropped silently. So `SAVE_KEY` moves to `spill.run.v5` and v4 saves are dropped on purpose, which makes this a **major** release, as with Milestones 8 and 9. Essence is granted once per run, in the action handler that ends it (not an effect), and also when a run that was already lost (or won on the final fight) is abandoned, restarted, or replaced before See results / Finish run is pressed (`unconfirmedEssence` in `useRun.ts`, same grant key, so it can't pay twice); and the grant is recorded in `spill.meta.v1` under the key `seed:startedAt:actionCount` (the last 50 kept), so it never pays twice. `useMeta` starts every change from storage and listens for `storage` events, so two open tabs never overwrite each other's Essence or unlocks. A finished run's save is cleared, so a reload never shows its Run End again.

### Milestone 10.6: Gold Paint (Issue #12)

| Spell | Cost | Base | `+` |
